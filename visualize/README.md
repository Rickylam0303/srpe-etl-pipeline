# Dashboard screenshot

Save your Excel dashboard export here as **`dashboard.png`** for the GitHub README hero image.

## Recommended steps

1. Open your `SRPE_Dashboard.xlsx` (or equivalent) connected to `vw_sales_detail`.
2. Hide gridlines and crop to the dashboard area only.
3. Export or screenshot at readable resolution (1280px+ width).
4. Save as `visualize/dashboard.png` and commit.

## Minimum viable portfolio

A clear screenshot plus working pivot tables is enough — pixel-perfect formatting is optional.

## Suggested charts to include

- Monthly transaction volume (`pasp_month`)
- Average price by block (`block_name`)
- Payment method mix (`payment_category`)
- KPI tiles: total transactions, termination rate, avg price
